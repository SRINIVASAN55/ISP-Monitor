# Contributing to ISP-Monitor

Thank you for considering contributing! Here's how to get started.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/ISP-Monitor.git`
3. Create a feature branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Test your changes thoroughly
6. Commit: `git commit -m "feat: describe your change"`
7. Push: `git push origin feature/your-feature-name`
8. Open a Pull Request

## Commit Message Format

Use conventional commits:
- `feat:` — new feature
- `fix:` — bug fix
- `docs:` — documentation only
- `chore:` — maintenance

## Reporting Issues

- Check existing issues first
- Include OS, Python version, and full error output
- Steps to reproduce are very helpful

## Code Style

- Follow PEP 8
- Add comments for non-obvious logic
- Keep functions focused and small
